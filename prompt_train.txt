config

- if there exists config file in the experiment dir, and if it does not matches with the given config, raise error 
- if args.config is not given and it's resuming run, load config from the experiment dir.
- get global_batch_size instead of (micro) batch_size, where global_batch_size = micro_batch * accum_steps * world_size
- vae_class: str (class name)
- vae_config: dict (vae = vae_class(**vae_config))

data: args.data_path (imagenet path)

checkpoints

- save last ckpt (last.pt) by every args.last_ckpt_every
- save ckpt (e.g., 00100.pt) by every args.ckpt_every
- resume last option: args.resume_last -> resume from last.ckpt (Find by exp_name with exps_dir)
